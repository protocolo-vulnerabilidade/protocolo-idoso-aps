# apps/frontend

Interface web do **Protocolo Idoso APS** — aplicação de uso pela equipe da UBS (ACS, enfermagem, medicina, eMulti e coordenação) para identificação, estratificação e acompanhamento da vulnerabilidade da pessoa idosa.

## Papel

- Apresentação e entrada de dados (aplicação assistida dos instrumentos, painel de indicadores, gestão de PTS)
- Consumo da **API do backend** — não implementa regras de estratificação (IVCF-20, EASFI-BR, matriz MIV-CFS, marcadores sentinela)

## Status

**Pendente de implementação.** A stack será definida e registrada em ADR (`docs/decisoes/`).
